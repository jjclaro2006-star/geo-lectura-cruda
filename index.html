Qué es esto, exactamente

Esta lectura no es una verificación de GPS ni del reloj del teléfono: es el valor crudo que navigator.geolocation devolvió en ese instante, con la incertidumbre que el propio dispositivo declaró como precisión.

  • Sin servidor: todo el cálculo ocurre en este navegador. La página no hace ninguna petición de red — puedes verificarlo leyendo el código fuente, que no contiene ningún fetch ni script externo.
  • Sin guardar: el resultado vive sólo en esta pestaña, mientras esté abierta. Recargar o cerrar la página lo borra.
  • Sin redondear: latitud, longitud, precisión y hora se muestran con el mismo texto que produce el navegador internamente — nunca con toFixed ni ningún ajuste manual.
  • Abrir esta página no autoriza tomar la muestra: eso ocurre únicamente al presionar el botón, y sólo entonces el sistema pide permiso de ubicación.
  • Sin inicio de sesión: esta página es HTML/CSS/JS estático servido por GitHub Pages — no requiere ninguna cuenta para abrirse.
